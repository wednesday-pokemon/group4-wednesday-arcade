# Engineering Decisions (rules v2.5)

Precedence: master prompt locked rules → GDD v2.5 PDF → visual guide (art only) → these defaults.

| ID | Decision | Rationale |
|---|---|---|
| D-01 | Stack: TypeScript + Vite + React 18 (menus/dashboard) + Three.js 0.170 (race scene) + Supabase. | Prompt §2; React keeps multi-screen/dashboard state simple. |
| D-02 | All simulated time stored as **integer centiseconds**; displayed as seconds with 2 dp. | Base seconds × integer % and all delays are exact at 0.01 s, so local, server and tests agree bit-for-bit (no float drift). Score = (eggs×10000 − timeCs)/100. |
| D-03 | Keyed RNG: every trusted draw is `keyedUniform(seed, "L{n}:{event}")` (FNV-1a + murmur3 finalizer, 53-bit). | Fixed draw keys mean a skipped conditional roll never shifts later rolls (prompt §6.5); pure integer math is identical in browser/Node/Deno. Not cryptographic — the *seed* is the secret (128-bit random from `crypto.getRandomValues`), and it never leaves the server before the session ends. |
| D-04 | Yoko + Dragapult at push level 3: discount = max(24, 30) = 30 %, cost 4. | Both abilities redefine the same level-3 value; taking the larger avoids inventing an unapproved stack. Dragapult's all-route +10 still applies on top. |
| D-05 | Xavier and Rowan consume their flag on the **first crash of the race** (not first crash that would hurt). | Prompt wording "first crash of entire race". |
| D-06 | Gengar's flag is only consumed when a weather delay would actually be > 0 after cancellations (Jellicent/Chandelure). | "First nonzero weather delay"; cancellations take priority over partial reducers. |
| D-07 | A Rowan-negated crash is still recorded as `crashOccurred=true, crashNegatedBy='rowan'` for telemetry, with zero effects. | Diagnostic transparency. |
| D-08 | Stamina is deducted at resolve (the prepared cost is locked at prepare). DNF legs still deduct stamina. | Prepare must not resolve anything; resolve is the single atomic transition. |
| D-09 | Leg time is computed and added to total even on a DNF leg (descriptive only); DNF score = 0, unranked. | Prompt: DNF score 0; analytics still need the leg time. |
| D-10 | Gap at leg start can never be ≤ 0 in normal flow (a ≤ 0 gap is always a catch, then reset to 30 m or DNF). Decidueye's "pre-existing ≤ 0" rule is implemented and unit-tested with a constructed state. | Faithful to rule while noting it is unreachable in normal play. |
| D-11 | Rounding: values are exact in centiseconds so no rounding is required for time/score; `formatSeconds` prints 2 dp. | Prompt "2 decimal places, deterministic". |
| D-12 | Shared rules are copied into `supabase/functions/_shared/game` by `scripts/sync-shared.mjs` (run on build) and a test asserts the copy is identical. | Deno Edge Functions can only bundle files under `supabase/functions`; one source of truth. |
| D-13 | Second (DNF) Hyde catch applies **no** catch penalties (no +10 s, no −35 HP, no egg loss, no gap reset); `gapEndM = gapBeforeCatchM`. The leg time without catch delay is still recorded. | Resolves design-review F-1: the prompt says second catch is "immediate DNF, independent of HP"; DNF is the penalty and the score is 0 either way. |
| D-14 | Morticia's first-catch time penalty is **5 s total**. | Design-review F-2; matches ability text "+5 instead of +10". |
| D-15 | No upper cap on pursuit gap; safe route `crashProbability = 0`. | Not specified anywhere; inventing a cap would alter approved math. |
| D-16 | Stamina disabled reasons use natural wording per remaining legs (design-review F-10). | Arcade readability. |
| D-17 | Unreachable-in-play rules (10 s floor, HP ≤ 0 DNF, 0.95 Hyde cap, Gengar+Jellicent/Chandelure, Xavier+Rowan) are implemented exactly and unit-tested with constructed inputs. | Design-review F-3..F-7: the roster makes some pairings impossible (one character + one Pokémon), but the rules must stay faithful. |
| D-18 | Cinematics target ~9 s per leg (≈5 s reduced-motion) rather than the reviewer's 22–30 s suggestion; Skip after 2 s. | Keeps the 75–85 s per-leg budget comfortable for decision + advice reading time; prompt asks for "brief animated race". |
| D-19 | Trusted keyed draws use a **SHA-256 PRF** (`src/game/sha256.ts`, pure TS, synchronous) instead of FNV/murmur. | backend-architect proved (SECURITY.md T-06b) two revealed leg-1 draws predicted every later roll with the old hash. SHA-256 keyed by a secret 128-bit seed removes that; `supabase/tests/unit/rng-leak.test.ts` now asserts the original attack fails. Synthetic data + models were regenerated afterwards. |
| D-20 | `LegResolution.draws` is `LegDraws | null`: the live server still redacts draws while a session is in progress and reveals them with the seed at the end. | Defence in depth on top of D-19; UI never needs raw draws during play. |
| D-21 | Live server contract extensions accepted from backend-architect: RPC envelopes `{ok, replay, response}`, column-level grants, idempotent `create-session` with actionId + per-station rate limit, `operator_audit`, `release_station`, `idle` station status, station-before-session lock order, ms timestamps, 404 for other stations' sessions, immutable leaderboard rows. | Each strengthens idempotency/security without touching game math (rationale in SECURITY.md §4). |
| D-22 | **v3 real-time overhaul** (client revision prompt) supersedes the decision-based race as the primary loop. New code lives in `src/action/**` (pure logic) and `src/three/action/**` (rendering), reached at `/?mode=play`. The v2.5 engine, screens, backend and leaderboard are kept intact until the v3 flow replaces them, so nothing working is lost mid-overhaul. | Phase-by-phase delivery with a runnable build after every phase. |
| D-23 | Rowing physics: one impulse per genuine SPACE press (key-repeat ignored), 0.14 s cadence cap (≈7 taps/s), impulse × (1 − (v/vmax)²) diminishing returns, exponential + linear drag at a fixed 120 Hz step. Measured: 2 taps/s ≈ 7 u/s, 3/s ≈ 8.5, 6/s ≈ 10 (unit-tested); W glides to 3 u/s; H toggles hold-to-row (3 strokes/s) for accessibility. | Client parameters (impulse 1.2, max 12, steer 2.4) with fairness: mashing cannot beat rhythm. |
| D-24 | Collisions: first touch = impact (speed cut by angle, deflection, damage once per 1.5 s per obstacle, 0.6 s global grace); sustained contact = per-second drag only, cooldown refreshed while scraping. Shore = slide, never damage. | Playtest showed per-step speed loss pinned the boat to a rock (unfair); fixed and regression-tested. |
| D-25 | **User decision:** the player CHOOSES the egg in Stage 2. Clues lead to all three: Common (near, easy), Rare (further, behind hazards), Legendary (deep crypt, guarded). Supersedes the GDD v3 seeded tier roll. | Designer showed the tier roll drove ~90 % of score variance; user chose skill over luck. |
| D-26 | **User decision:** v3 ranking puts every finisher above every DNF. Score = delivered egg points × 100 − active gameplay seconds (negative finishes allowed); DNFs only appear in the defeated log. | Prevents a DNF (0) outranking a slow Common finish. |
| D-27 | **User decision:** egg points stay whole numbers (1/3/6). Gholdengo's +0.5 point bonus is replaced by a non-point egg-protection effect. | Integer scoring and leaderboard. |
| D-28 | Rowing feel for Phase 2: keep the tested Phase 1 tuning until the user reports how it plays; the designer's tougher alternative stays in `src/action/data/stages.ts` (ROWING_DEFAULTS) for comparison. | User will give feedback after playing. |
| D-29 | Phase 1 correction root cause: no screens were deleted — `/` still served the v2.5 home/selection/decision flow, while the rowing trial lived at a separate `/?mode=play` with dropdowns. Fix: v3 journey becomes the default at `/` (Home → Nickname → Character → Pokémon → Confirm → Tutorial → Stage 1); legacy decision race kept at `/?legacy=1`. No git history existed (no commits), so nothing needed recovery. | Investigated before changing anything, per the correction prompt. |
| D-30 | Portraits: the original cards used monogram badges (the first brief forbade fetching unlicensed art). The client asked for portraits, so the 30 images embedded in the client's own Visual Reference Guide PDF were extracted (position-sorted, verified visually) to `public/art/{characters,pokemon}/<id>.webp` (271 KB total). **Rights note:** the guide labels them concept/illustrative, not licensed official artwork, and several Pokémon images resemble official art; public use beyond the school event should be cleared by the client. | Client-supplied asset, explicit client request; caveat recorded. |
| D-31 | Stage 1 becomes an open haunted lake (land polygons, ≥3 routes, landmarks, encounter director) with a real Hyde pursuer and a data-driven ability interpreter, per `docs/V3_STAGE1_CONTRACT.md`. | Client feedback: "not Subway Surfers with a boat"; Hyde must be visible and able to catch. |
| D-32 | Stage 1 Hyde retuned to be a felt threat (orchestrator ruling, from game-developer measurements): before, no steady rower ever had him within 15 u. Now `hyde.stage1` startGap 26, floorSpeed 7.45 (≈ 2 taps/s), targetGap 16.5, rubberK 0.1, paceFactor 0.95, maxSpeed 13; lunge is a 1.2 s snap that a boat holding pace survives (3 s cooldown); surges hold at ~10 u; Hyde paces off ground speed; warnings at 15 u / 9 u. Measured on lake.ts: clean 3 taps/s → 0 catches (closest 9.9 u, steady 18–22 u); 2–2.5 taps/s with stops/crashes → 2 of 12 caught; 1.5 taps/s → caught once, still finishes; idle → DNF at 60 s. All 216 pairs finish the safe route at 3 taps/s with 0 catches. Basculegion's lead bonus threshold 50 → 25 u to stay reachable. Rowing (D-28) untouched. | Client criteria "Hyde reacts / can catch / fair escape"; tests in tests/unit/action/{hyde,endToEnd}.test.ts lock the targets. |
| D-33 | Gholdengo passive `pristine_bonus_points` (+0.5 pt) replaced by `egg_security_floor` 40 (applies from Stage 3). | Enforces D-27 (whole egg points). |
| D-34 | **User decision (portraits):** new client-supplied JPEGs in `public/art` are used where they are genuine (Ajax, Bianca, Enid, Wednesday, Xavier, Yoko, Gengar → cropped to 320² `.webp`); `Divina.jpeg`/`Kent.jpeg` are copies of Yoko's portrait and `Marowak.jpeg`/`Misdreavus.jpeg` copies of Gengar, so those keep the original portraits. The 18 deleted Pokémon `.webp` files were restored from `dist/`; replaced originals backed up in `D:\PokemonDay-cache\art-backup-webp`. **Rights note:** the new Gengar image carries an "Additional artwork" caption (official artwork from a website) — same D-30 caveat applies. | User chose "use new, fill gaps"; avoids showing a wrong face. |
| D-35 | **User master revision v3.1** (2026-10-21): `Escape_from_Raven_Island_Game_Development_Plan_v3_1.pdf` + master prompt v3.1 are the current source of truth (saved in `docs/v3.1/`). Supersedes the rowing design (D-22…D-24, D-28, D-31, D-32), separate character/Pokémon selection and character-gated analytics. Still in force: D-26 (every finisher above every DNF; score = egg points × 100 − active seconds), D-27 (whole egg points; Gholdengo = egg protection), D-30/D-34 (portrait rights caveat). Legacy builds stay reachable (`/?legacy=1`, `/?mode=rowing`; tag `pre-mystery-v3.1`). | Owner changed the game to a third-person mystery/stealth/egg-extraction design. |
| D-36 | **User decision (Pokémon visuals):** all 18 partner images come from PokéAPI (`https://pokeapi.co/api/v2/pokemon/{form}` → official artwork). `npm run art:pokeapi` resolves the exact form (marowak-alola, corsola-galar, aegislash-shield, jellicent-male, basculegion-male, default decidueye) and caches 320² transparent `.webp` + `pokeapi-manifest.json` (source URLs) in `public/art/pokemon/`, so kiosks never depend on the venue network at runtime. Previous images backed up in `D:\PokemonDay-cache\art-backup-webp\pokemon-before-pokeapi\`. **Rights:** this is official Pokémon artwork (© Nintendo / Creatures / GAME FREAK / The Pokémon Company), served by PokéAPI but not licensed by it — acceptable risk for a non-commercial school event per the owner; clear rights before any public/commercial use (extends D-30). | Owner request; build-time cache for kiosk reliability. |
| D-37 | **3D partner models (in-world companion).** The mystery companion (`src/three/mystery/characters.ts` `Companion`) shows a real GLB model when one is available; fallback order: 3D model → PokéAPI artwork billboard (D-36) → procedural stand-in. Models are identified by National Pokédex number + form (`src/three/pokemonModels/refs.ts`), never by name. Providers, first hit wins: `local` (build-time cache `public/models/pokemon/` + `manifest.json` with sha256, written by `npm run art:models3d`, which cross-checks each dex number/form against PokéAPI) then `community` (`https://pokemon-3d-api.onrender.com/v1/pokemon`, optional/unguaranteed; model URLs only from `raw.githubusercontent.com`). Override with `VITE_POKEMON_MODEL_PROVIDERS` or `?pokemon3d=local|community|off`. Draco decoder vendored in `public/draco/` (no CDN at runtime). Galarian Corsola has no working model upstream (catalog URL 404s) → artwork. Dhelmise's source faces +X (`modelYaw`). Several rigs ship no animation and render in bind/T-pose; idle loops are played when the GLB has one. **Rights:** models come from Sketchfab via the community pipeline; Pokémon designs © Nintendo / Creatures / GAME FREAK / The Pokémon Company — same non-commercial-event caveat as D-36. | Owner request for real 3D Pokémon; local-first keeps kiosks independent of the venue network (as D-36); the companion is the only in-world Pokémon, and the duo cards stay 2D to avoid extra WebGL contexts. |
