# Theme — "Nevermore Lantern" (custom, via theme-factory)

Derived from theme-factory's *Midnight Galaxy* base and re-keyed to the GDD art direction (lake at night, crypt stone,
lantern light). The one bold element is **lantern amber**: it marks the primary action, the focus ring and the
player's boat light. Everything else stays quiet so the 3D scene carries the drama.

| Token | Hex | Role |
|---|---|---|
| Lake Night | `#0b1020` | page/canvas background |
| Crypt Indigo | `#161a3a` | panels, HUD surfaces |
| Raven Violet | `#8b7cf6` | secondary accent, selection outlines |
| Lantern Amber | `#f5b04c` | primary action, focus ring, highlights |
| Parchment | `#efe6d2` | primary text |
| Hyde Crimson | `#e5484d` | danger, Hyde, DNF |
| Egg tiers | `#f3eee2` / `#5ee0f0` / `#f2c14e` | common / rare / legendary |

Typography: **Cinzel** (display — inscriptional capitals of crypt stonework; headings only) and **Alegreya Sans**
(humanist sans for all UI/body text; very legible at arcade distance). Both self-hosted via `@fontsource` so the
kiosks never depend on a font CDN.
